ЛИТВИНVERSE — как запустить

1. Распакуй архив.
2. Для Vercel нужен файл index.html в корне проекта.
3. Самый простой способ с телефона:
   - Открой https://vercel.com/ и войди/создай аккаунт.
   - Открой https://github.com/ и создай новый репозиторий.
   - Загрузи в репозиторий файл index.html из этого архива (Add file → Upload files).
   - Вернись на Vercel → Add New → Project → Import Git Repository.
   - Выбери репозиторий с index.html → Deploy.
   - Когда сборка закончится, открой выданную ссылку *.vercel.app.
4. Для этого статического сайта не нужны Build Command и Output Directory. Если Vercel спрашивает Framework Preset, выбери Other.
5. Прогресс игры сохраняется локально в браузере устройства, поэтому на другом устройстве баланс может быть отдельным.

Важно: это один готовый HTML-файл. Мем-звуки сделаны синтезированными браузерными эффектами, а не скачанными оригинальными записями.
