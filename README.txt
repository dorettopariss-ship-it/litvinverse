ЛИТВИН — клуб романтики (мемная школьная история)

Как открыть:
1. Распакуй ZIP в отдельную папку.
2. Открой index.html в браузере (Chrome, Edge, Safari).
3. Интернет не нужен: история и фотографии находятся внутри папки.

Чтобы выложить онлайн:
- Загрузи всю папку на GitHub как репозиторий и включи GitHub Pages, либо импортируй папку/репозиторий в Vercel.
- Не загружай только index.html: папка assets с фото нужна для иллюстраций.

Сайт адаптируется под телефон и компьютер. В нём 8 глав, навигация по главам, прогресс и шуточные варианты выбора.
