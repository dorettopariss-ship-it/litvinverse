ЛИТВИНVERSE 2.0 — загрузка и онлайн-бомбочки

Файлы: index.html — весь сайт в одном файле.

ОБНОВЛЕНИЕ НА GITHUB С ТЕЛЕФОНА
1. Распакуй ZIP.
2. Открой репозиторий GitHub litvinverse.
3. Открой index.html → меню с карандашом Edit или Add file → Upload files.
4. Замени старый index.html новым из архива и нажми Commit changes.
5. Vercel обычно сам опубликует новую версию после commit.

НАСТРОЙКА РЕАЛЬНОГО ОНЛАЙНА
1. Создай проект на https://supabase.com/dashboard
2. В Project Settings → API скопируй Project URL и publishable key (или anon public key). Не используй secret/service_role key в браузере.
3. На опубликованном сайте прокрути до «Бомбочки онлайн», вставь URL и public key, нажми «Подключить».
4. Игрок 1 нажимает «Создать комнату» и отправляет код игроку 2. Игрок 2 вводит код и нажимает «Войти по коду».
5. Оба должны открыть одну и ту же опубликованную версию.

Важно: это браузерный прототип с Supabase Realtime Broadcast. Реальное соединение зависит от правильно созданного Supabase проекта, корректных URL/key и доступности Realtime. Проверь его двумя разными браузерами/устройствами до того, как делиться сайтом. Не вставляй приватный secret/service_role ключ. Звуки мемной панели пока синтезированные; для оригинальных мемных аудиофайлов нужно добавить конкретные легально доступные mp3/ogg файлы.
