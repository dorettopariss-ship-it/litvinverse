⚙️ Настройка Supabase — один раз

  1. Открой supabase.com/dashboard и создай бесплатный проект.
  2. В Project Settings → API найди Project URL и publishable key (или anon public key).
  3. Вставь их в поля выше и нажми «Подключить». В Supabase открой Database → Replication/Realtime и проверь, что Realtime включён.
  4. Сохрани сайт в Vercel после обновления файлов. Оба игрока открывают одну ссылку и используют один код комнаты.

Онлайн использует Supabase Realtime Broadcast. Если не подключить свой проект, режим не будет выдавать себя за рабочий онлайн.
